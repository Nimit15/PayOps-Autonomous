# Rubric Contract

## Judging Criteria & Mapping

| Criterion (Weight) | Mapping to Modules/Invariants |
| :--- | :--- |
| **Technological Implementation (20%)** | PayPal API/MCP integration, E2E tests, OAuth2, Webhooks |
| **Design (20%)** | AG Studio dashboard, Bryntum timeline styling |
| **Potential Impact (20%)** | Autonomous Procurement, Dispute Triage |
| **Innovation / Idea (20%)** | Agentic Commerce, Closed-loop webhook orchestration |
| **Presentation (20%)** | <3 min Video, Demo Mode |

- Bryntum (Gantt tied to payment states)
